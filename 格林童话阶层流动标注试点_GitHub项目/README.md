# CUS6043 格林童话阶层流动标注

试点阶段。六位组员各自独立标注同一批 20 篇，合计 120 条记录。

## 打开工具

双击 `index.html`，或打开本项目的 GitHub Pages 网址。请把网址发给六位组员。也可以直接转发 `index.html`，它已经内置试点篇目的英文全文和自译中文。

## 组员操作

1. 阅读「编码说明」，输入中文全名领取任务。组员代号在试点开始时随机抽取并固定。
2. 阅读区默认逐段中英对照，也可以切换到「仅英文」或「仅中文」。标注以 Margaret Hunt 英译底本为准。选「不适用」时，其余字段留空。选「适用」时，按表单完成必填项，备注可留空。
3. 进度自动保存在当前浏览器。换电脑、换浏览器或从本地文件切换到 GitHub Pages 前，先用「备份 CSV」，再在新入口输入同一姓名并使用「导入备份」。
4. 完成 20 篇后，用「导出试点 CSV」，将文件私下交给负责人。请保留工具导出的原始 CSV，便于直接导入。

## 负责人操作

1. 从首页进入「负责人汇总试点结果」，导入六位组员各自的完整 CSV。
2. 收齐六份后，点击篇目展开明细，或勾选「只看分歧」。工具按原工作簿的规则比较适用性、开头阶层、结局阶层、流动类型和主要方式，计算不同的非空值。
3. 导出「汇总 CSV」和「分歧表 CSV」。汇总 CSV 的 11 列与原工作簿「试点标注」一致，数据按原来的篇目和 A–F 顺序排列。可把 CSV 的 A2:K121 粘贴到工作簿的「试点标注」A2:K121。请在关闭汇总页前导出结果，导入记录只保留在当前页面。
4. 小组据此讨论分歧，再按原工作簿流程记录共识。当前工具覆盖独立试点和结果汇总。

## 发布到 GitHub Pages

将解压后的文件和目录上传到仓库根目录，确保 `index.html` 在顶层。仓库的 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)**，保存后把生成的网址发给组员。如果默认分支叫别的名字，选实际分支。

这个工具使用姓名匹配任务，姓名是分工入口。静态网页及项目源码包含六位组员姓名，访问公开网页或仓库源码的人可以查看。答案和草稿保存在组员自己的浏览器或导出的 CSV 中，组内私下传递结果文件。

## 源码与语料

- `sources/` 包含原始 Excel 与语料 ZIP。
- `tool-source/` 包含页面模板、样式、脚本、固定分工表和生成脚本，`tool-source/translations/` 保存逐段中文译文。修改源文件后，从仓库根目录执行 `python -m pip install openpyxl` 和 `python tool-source/build_pilot.py`，重新生成 `index.html`。普通使用和发布只需要现成的 `index.html`。
- 童话取自 Margaret Hunt 1884 年英译的 *Household Tales*，使用随附的 Standard Ebooks 校订语料。KHM 153《The Star-Money》在压缩包内的文件名为 `154_the-star-money.txt`。
